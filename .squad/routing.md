# Routing

Explicit @name or Name, task wins. Otherwise match expertise; ambiguous work goes to Lead.
Only independent read jobs run in parallel in the shared checkout. Multiple writers require managed worktrees.

- Lead: architecture, design, 架构, 设计, PRD
- Frontend: React, UI, CSS, 前端, 页面
- Backend: API, database, server, 后端, 数据库
- Tester: test, review, QA, 测试, 审查
- Scribe: memory, decisions, retro, 记忆, 复盘
- Ralph: issue, backlog, triage, 待办
- Rai: security, privacy, safety, 安全, 隐私
